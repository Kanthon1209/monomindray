# 1. Header

高度约 `60~64px`。

横向布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ Logo     IVD产品应用价值平台                                  │
└──────────────────────────────────────────────────────────────┘
```

左侧：

* Mindray / 迈瑞 Logo
* 平台名称

目前截图里没有明显的菜单、用户头像、登录按钮，所以**先不要添加这些东西**。

## 2. Filter Bar

Header 下方是一行筛选区域。

```text
┌──────────────────────────────────────────────────────────────┐
│ 当前区域   医院级别   医院类型   开展装置   设备型号             │
│ [全国 ▼]  [全部 ▼]   [全部 ▼]   [全部 ▼]   [全部 ▼]            │
└──────────────────────────────────────────────────────────────┘
```

这是一个横向 Flex 布局。

每个筛选项：

```text
label
  ↓
select
```

截图里这些筛选器基本处于同一水平线上。

# 3. Main Content

这是页面真正的核心。

采用 **左右两栏布局**：

```text
┌──────────────────────────────────────────┬──────────────────────┐
│                                          │                      │
│                                          │                      │
│                 Map                      │    Hospital Panel    │
│                                          │                      │
│                                          │                      │
│                                          │                      │
└──────────────────────────────────────────┴──────────────────────┘
```

比例大约：

```text
Map          70%
Hospital     30%
```

我建议代码直接采用：

```css
grid-template-columns: minmax(0, 7fr) minmax(360px, 3fr);
```

这样右侧医院列表不会因为窗口缩小而变得太窄。

# 6. 所以 Next.js 页面组件可以先定成

```text
app/
├── page.tsx
└── components/
    ├── Header
    ├── FilterBar
    ├── MainContent
    │   ├── ChinaMap
    │   └── HospitalPanel
    │       ├── HospitalHeader
    │       ├── HospitalSearch
    │       ├── HospitalTable
    │       └── Pagination
```

最终 `page.tsx` 的结构非常简单：

```tsx
<Page>
  <Header />

  <FilterBar />

  <MainContent>
    <ChinaMap />
    <HospitalPanel />
  </MainContent>
</Page>
```

### 页面高度

建议：

```css
height: 100vh;
display: grid;
grid-template-rows: 64px 64px minmax(0, 1fr);
```

这样：

* Header 固定
* FilterBar 固定
* **地图 + 医院列表占据剩余全部空间**
* 医院列表自己滚动
* 页面整体尽量不出现浏览器级别的纵向滚动条

这个布局先确定下来，后面再定**每个区域具体用哪些 shadcn/ui 组件**。
